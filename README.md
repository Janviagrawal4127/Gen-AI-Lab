# 🤖 Generative AI Lab – 10 Experiments

A collection of 10 practical Generative AI experiments implemented using Python, TensorFlow, PyTorch, Transformers, and other AI/ML libraries.

This repository demonstrates the fundamental concepts and applications of Generative Artificial Intelligence, including neural networks, image generation, language models, prompt engineering, and ethical AI.

## 📌 Project Overview

**Project Name:** Generative AI Lab

**Programming Language:** Python

**Environment:** Python 3.11

**IDE:** Visual Studio Code

**Repository:** [Gen-AI-Lab](https://github.com/Janviagrawal4127/Gen-AI-Lab)

## 🎯 Objectives

- Understand the fundamental concepts of Generative AI.
- Implement encoder-decoder architectures and autoencoders.
- Explore Generative Adversarial Networks (GANs).
- Understand attention mechanisms and Transformers.
- Fine-tune pre-trained language models.
- Develop document-based question-answering chatbots.
- Experiment with prompt engineering and LLM creativity.
- Analyze potential bias in Large Language Models.
- Generate images using text prompts.
- Explore DeepFake technology and its ethical implications.

## 🧪 Experiments

| No. | Experiment | Description |
|---|---|---|
| 1 | Encoder-Decoder Model | Implement a sequence-to-sequence model for word reversal. |
| 2 | Autoencoder | Compress and reconstruct handwritten digit images using MNIST. |
| 3 | Generative Adversarial Network (GAN) | Generate new handwritten digit images using GANs. |
| 4 | Attention Mechanism | Visualize attention weights in a pre-trained translation model. |
| 5 | Transformer Fine-Tuning | Fine-tune a pre-trained T5 model for text summarization. |
| 6 | Document-Based Chatbot | Build a question-answering chatbot using a pre-trained LLM and document retrieval. |
| 7 | Prompt Engineering | Explore different prompts and temperature settings to control LLM outputs. |
| 8 | LLM Bias Analysis | Analyze potential gender and racial biases in generated responses. |
| 9 | Text-to-Image Generation | Generate images from natural language prompts using Stable Diffusion Turbo. |
| 10 | DeepFake Analysis | Examine video artifacts and discuss the ethical implications of DeepFake technology. |

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/Janviagrawal4127/Gen-AI-Lab.git
```

### 2. Navigate to the project directory

```bash
cd Gen-AI-Lab
```

### 3. Create a virtual environment

```bash
uv venv --python 3.11 .venv
```

### 4. Activate the environment

**Windows PowerShell:**

```powershell
.venv\Scripts\Activate.ps1
```

### 5. Install dependencies

```bash
uv pip install -r requirements.txt
```

## ▶️ How to Run

Each experiment can be executed independently.

For example:

```bash
python Experiment_1.py
```

```bash
python Experiment_2.py
```

Similarly, run any experiment from `Experiment_1.py` to `Experiment_10.py`.

### Special Instructions

- **Experiment 4, 5, 7, 8 and 9:** Internet access is required to download pre-trained models or datasets on the first run.
- **Experiment 6:** Keep `document.txt` in the project directory.
- **Experiment 9:** GPU acceleration is recommended for faster image generation.
- **Experiment 10:** Provide a valid MP4 or AVI video file for analysis.

## 📚 Learning Outcomes

Through these experiments, the following concepts are explored:

1. Sequence-to-sequence learning and encoder-decoder architecture.
2. Latent space representation and image reconstruction.
3. Adversarial training using generator and discriminator networks.
4. Attention weights and Transformer-based translation.
5. Transfer learning and fine-tuning of pre-trained models.
6. Retrieval-based question answering and LLM applications.
7. Prompt engineering and temperature-based generation.
8. Responsible AI, fairness, and bias evaluation.
9. Text-to-image synthesis using diffusion models.
10. DeepFake detection challenges, digital ethics, and responsible AI.

## ⚖️ Ethical Considerations

Generative AI offers significant opportunities but also introduces challenges.

This project explores important ethical concerns, including:

- Gender and racial bias in AI-generated content.
- Privacy and consent in synthetic media.
- Misinformation and manipulated videos.
- Responsible use of AI-generated images.
- Transparency and accountability in AI systems.
